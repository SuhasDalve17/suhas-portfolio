## Deployment

You can deploy this website using:
- GitHub Pages
- Netlify
- Vercel

## GitHub Pages Deployment

1. Create new repository
2. Upload files:
   - index.html
   - style.css
   - README.md
3. Go to:
   Settings → Pages
4. Select:
   Deploy from Branch → main
5. Save

Your site will be live in few minutes.
